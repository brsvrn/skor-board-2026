## DataSportsAPI integration
Verified country directory and fixtures. Fixed league allowlist, Redis-backed 80 requests/day and 8/minute cap (below post-beta free allowance), stale fallback, today 20 minute cache, future/past 6h, standings 6h. Namespaced DS IDs preserve old ESPN hashes. Lower league push not integrated; details restricted to available score, venue, referee and managers, no fabricated statistics. Current manager fields are not necessarily historical match coaches. Turkish Super Lig enrichment requires exact normalized names and kickoff within ten minutes. No international enrichment yet. Standings group coverage must be verified from live data.
